# Roomio 🏠

A shared-living app to help roommates organize expenses, chores, and everyday essentials in one place.

## About

Roomio is a full-stack web application currently under development. The goal is to make living with roommates simpler through shared spaces, expense tracking, chore management, and collaborative shopping lists.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- PostgreSQL
- Drizzle ORM
- Docker

## Project Status

🚧 **In Development**

The project is being built incrementally, with a focus on clean architecture, secure development practices, and a reliable user experience.

## Planned Features

- Shared spaces and roommate invitations
- Shared expense tracking and balance calculations
- Chore management
- Shared shopping lists
- A dashboard for household activities

## Development

Setup instructions, environment configuration, database migrations, and testing commands will be added as the project develops.
